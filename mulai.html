Memulai Microsoft Excel

Pelajari antarmuka dan dasar-dasar penggunaan

Membuka Microsoft Excel

Ada beberapa cara yang dapat dilakukan untuk mengaktifkan program aplikasi Microsoft Excel, yaitu sebagai berikut:

  • Melakukan double klik shortcut Microsoft Excel di desktop.
  • Melalui menu Start, yaitu dengan mengklik Start > All Programs > Microsoft Office > Excel.
  • Melalui file yang terdapat di Microsoft Excel, dengan cara buka File Explorer, kemudian dobel klik file Excel.
  • Dengan mengetikan kata "excel" di Run Command. Run Command bisa dipanggil dengan menekan tombol Windows + R, atau langsung diketik pada halaman Start di Windows.
Menu pada Microsoft Excel
  1. Menu Bar: Pada Microsoft Excel terdapat beberapa menu bar utama (Home, Insert, Page Layout, Formulas, Data, Review, View).
  2. Status Bar: Mempunyai dua area utama, yaitu Message pada bagian kiri dan kotak indikator pada bagian kanan. Tanda Ready menunjukkan Excel siap menerima perintah.
  3. Title Bar: Berada paling atas lembar Excel. Di dalamnya terdapat Minimize, Maximize, Close, Restore.
  4. Formula Bar: Berfungsi untuk memasukkan, memperbaiki, dan menampilkan data atau rumus pada sel yang sedang aktif.
  5. Petunjuk Sel (Cell Pointer): Untuk memindahkan penunjuk sel ke posisi yang baru dapat digunakan mouse maupun keyboard.

Tab pada Ribbon Microsoft Excel

Memahami Ribbon adalah hal yang sangat perlu dilakukan untuk memahami fungsionalitas Microsoft Excel. Pada Ribbon tercantum semua informasi, perintah, serta fungsi yang dapat kita gunakan.

  • Home: Tab utama untuk format teks, cells, jenis huruf, memasukkan/menghapus kolom, cell styles, format tabel, serta mengurutkan data.
  • Insert: Menyisipkan objek seperti Foto, Shape, Grafik, Text Box, PivotTable, dll.
  • Page Layout: Menyesuaikan halaman seperti margin, orientasi (portrait/landscape), dan tema cetak.
  • Formulas: Digunakan saat membuat rumus. Memiliki kumpulan fungsi (Function Library) yang besar.
  • Data: Memodifikasi lembar kerja dengan jumlah data besar (menyortir, filter, dan analisis).
  • Review: Memeriksa ejaan, tata bahasa, komentar, dan mengatur proteksi (keamanan) dokumen.
  • View: Mengubah tampilan dokumen, perbesaran (zoom), dan membekukan panel (Freeze Panes).
Elemen pada Microsoft Excel

Saat memulai Excel akan muncul sebuah dokumen kosong (Workbook). Di sinilah kita menambahkan data dan informasi.

  • Ikon Menu (File / Office Button): Berisi perintah dasar seperti New, Open, Save, Save As, dan Print.
  • Quick Access Toolbar: Tombol jalan pintas untuk perintah yang sering digunakan (Save, Undo, Redo).
  • Name Box: Kotak yang menunjukkan referensi atau alamat sel yang sedang aktif (misalnya A1).
  • Formula Bar: Tempat untuk menuliskan dan melihat isi formula/rumus dari sel.
  • Kolom (Column): Lajur tegak berisi abjad A sampai XFD.
  • Baris (Row): Lajur mendatar berisi angka 1 dan seterusnya.
  • Tombol Navigasi Sheet: Untuk berpindah antar lembar kerja (Sheet1, Sheet2, dll).
  • Zoom: Memperbesar atau memperkecil tampilan layar kerja.
Menggunakan Menu dan Ikon

A. Menyimpan Lembar Kerja

  1. Klik ikon Save pada Quick Access Toolbar atau tekan Ctrl + S.
  2. Tentukan lokasi folder penyimpanan pada kotak dialog Save As.
  3. Isikan nama file pada kotak File Name.
  4. Klik tombol Save.

B. Menyimpan dengan Nama Baru

Gunakan perintah Save As (tekan F12) untuk menyimpan dokumen yang sama dengan nama file atau format yang berbeda tanpa menimpa file aslinya.

C. Membuka Lembar Kerja

Gunakan perintah Open (tekan Ctrl + O) atau klik ikon folder terbuka, lalu cari file Excel yang sudah pernah Anda simpan sebelumnya.
